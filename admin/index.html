This panel talks to Supabase through the local dev server, which holds the project's secret key. Supabase refuses secret keys sent from a browser, so the key never reaches this page.

Setup, once: copy the secret key (Project Settings → API Keys → Secret keys) into a file named .supabase-secret next to serve.py (it is gitignored), or export CORELINE_SECRET, then restart python3 serve.py.
